---
description: 依頼を種類分けし、手順書どおりに進める入口コマンド
---
依頼: $ARGUMENTS

1. まず依頼を自分の言葉で言い直す（2行）。Thor のタスク番号を確認する。無ければ作る。
2. 種類を1つ選び、その手順を ToDo に書き写す。飛ばす手順は「skip: 理由」と書く。
   - 調査（コードを変えない）: 調べる → 根拠になるファイル:行 を添えて答える
   - バグ修正: 再現する → 失敗するテストを書く → 直す → テストが通る出力を貼る
   - 機能追加: Plan mode で計画 → 了承 → 実装 → テスト → 動作確認の証拠
   - リファクタ: 振る舞いを変えない。前後でテスト結果が同じであることを示す
   - 不明・大きい: docs/design/ に短い設計メモを書いて止まり、壮宇に確認する
3. 完了チェックを作業前に書く。合否が出る形で書く（例:「npm test が全件パス」）。
4. 終わったら AGENTS.md の「Thor への報告」4項目で報告する。
